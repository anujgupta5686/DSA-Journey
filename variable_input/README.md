## 💻 How I Approach Each Problem

For every coding problem, I aim to follow this process:

1. Understand the problem statement.
2. Identify the input, output, and constraints.
3. Work through a small example manually.
4. Develop the logic before writing code.
5. Implement the solution in C++.
6. Test normal cases and edge cases.
7. Analyse time and space complexity where applicable.
8. Review mistakes and improve the solution.
9. Revisit the problem later and solve it without looking at the previous code.

My goal is not simply to memorise solutions, but to understand **why a solution works and when to use it**.
